# Implementation tasks

Check off each task as it is completed. The order follows the delivery plan in
[[specifications/milestones/0.0.1|Milestones and deliverables (v0.0.1)]].

## 1. Create the iPhone project

- [x] Create an Xcode iOS App project named **Book Catalog**.
- [x] Set the deployment target to iOS 17 or later.
- [x] Use SwiftUI for the interface and SwiftData for persistence.
- [x] Choose and set the app's bundle identifier.
- [x] Add a `.gitignore` for Xcode user data, build products, and local
  configuration files.
- [x] Configure an Open Library `User-Agent` containing the app name and a
  maintainer contact email.
- [x] Build and run the empty app in the iPhone Simulator.

### Acceptance criteria

- The project builds without errors and launches in an iOS 17+ simulator.
- The project uses SwiftUI and has a working SwiftData model container.
- No developer-specific Xcode files or local configuration files are tracked
  by Git.

## 2. Build the local data layer

- [x] Define the SwiftData `Book` model.
- [x] Store: title, authors, ISBN, publisher, publication date, language,
  description, and date added.
- [x] Make title required; allow all other book fields to be absent.
- [x] Make ISBN unique when it is present.
- [x] Configure the SwiftData model container.
- [x] Add a small data-access layer for creating, fetching, and deleting books.
- [x] Verify that a test book remains after restarting the app.

### Acceptance criteria

- A book with only a title can be created and saved.
- A second book with the same non-empty ISBN cannot create a duplicate record.
- Saved books persist after the app is terminated and relaunched.

## 3. Build the collection and details screens

- [x] Create the collection screen as the app's home screen.
- [x] Query books from SwiftData and sort them alphabetically by title.
- [x] Display title and author in each collection row.
- [x] Add an empty state with **Scan book** and **Add manually** actions.
- [x] Create a read-only book-details screen.
- [x] Add deletion from book details, with a destructive-action confirmation.

### Acceptance criteria

- The collection shows every saved book in ascending alphabetical title order.
- Selecting a row opens the correct read-only book details.
- Deleting a book after confirmation removes it from the details and collection
  screens.

## 4. Add manual book creation

- [ ] Create an add-book form with title, authors, ISBN, publisher,
  publication date, language, and description.
- [ ] Validate that title is present before saving.
- [ ] Implement **Save** and **Cancel**.
- [ ] Allow the form to receive a prefilled ISBN after a failed lookup.
- [ ] Return to the collection after saving a manually entered book.

### Acceptance criteria

- Save is unavailable, or shows a validation error, when title is empty.
- A book with only a title saves successfully.
- Saving a valid form adds the book to the alphabetically ordered collection.
- A supplied ISBN remains prefilled when the form is opened from lookup
  fallback.

## 5. Implement barcode scanning

- [ ] Add the camera usage-description text to the app target.
- [ ] Request camera access when the user opens **Scan book**.
- [ ] Show an explanation and Settings link if camera access is denied.
- [ ] Create the scan screen with a camera preview and scanning frame.
- [ ] Recognize EAN-13 codes beginning with `978` or `979`.
- [ ] Ignore unsupported barcode types with a clear message.
- [ ] Pause scanning after the first valid ISBN is detected.
- [ ] Check SwiftData for an existing matching ISBN.
- [ ] Open the existing book's details when the ISBN is already stored.

### Acceptance criteria

- The app requests camera access with a user-facing reason for scanning books.
- A valid `978` or `979` ISBN barcode is detected only once per scan session.
- Unsupported codes do not create a book.
- Scanning an ISBN already in the catalog opens that book and does not create a
  duplicate.

## 6. Integrate Open Library

- [ ] Create an `OpenLibraryClient` responsible only for network lookups.
- [ ] Request book metadata using a scanned ISBN.
- [ ] Decode title, authors, ISBN, publisher, publication date, language, and
  description when available.
- [ ] Include the configured identifying `User-Agent` in requests.
- [ ] Show a loading state during the lookup.
- [ ] On one or more results, save the first result automatically.
- [ ] Return to the collection after automatic saving.
- [ ] If the network request fails or produces no result, open manual entry
  with the ISBN prefilled.

### Acceptance criteria

- A lookup request contains the configured `User-Agent`.
- When Open Library returns one or more results, the first result is saved
  without a confirmation or edit screen.
- When lookup fails or has no result, manual entry opens with the scanned ISBN.
- A failed lookup never loses the scanned ISBN or prevents manual saving.

## 7. Test the complete flow

- [ ] Test manual entry with only a title.
- [ ] Test a successful scan and automatic Open Library save on a physical
  iPhone.
- [ ] Test an ISBN that already exists in the catalog.
- [ ] Test an ISBN with no metadata result.
- [ ] Test offline behavior and camera-permission denial.
- [ ] Check alphabetical ordering after adding multiple books.
- [ ] Test deletion and persistence after relaunching the app.
- [ ] Verify VoiceOver labels and readable text sizes on every screen.

### Acceptance criteria

- All automated tests pass.
- The complete scan-and-save flow works on a physical iPhone.
- The manual-entry fallback works with no network connection.
- The app has no known crash in the tested flows.

## 8. Document and prepare delivery

- [ ] Add Xcode setup, build, and run instructions to the README.
- [ ] Document the Open Library `User-Agent` configuration without committing

- [ ] Review the app on a clean simulator install and a physical iPhone.
- [ ] Commit the finished v0.0.1 implementation to GitHub.

### Acceptance criteria

- A new developer can build and run the app using only the README.
- The repository contains no personal contact information or local-only
