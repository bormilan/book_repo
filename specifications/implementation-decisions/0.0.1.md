# Implementation decisions

These decisions are intentionally small and should guide the first working
version of the app.

## Duplicate ISBNs

Store one book per ISBN. If the user scans an ISBN that already exists in the
catalog, open that book's details instead of adding a duplicate.

## Manual entry

Manual entry supports books with no barcode or a failed Open Library lookup.

- Title is required.
- ISBN and author are optional.
- If a barcode was scanned, prefill the ISBN field.

## Failed metadata lookup

If Open Library cannot return a result—for example because the device is
offline or the ISBN is unknown—open the manual-entry form. A retry flow is out
of scope for the first version.

## Open Library requests

The app uses the free Open Library API and does not need an API key. Requests
include a `User-Agent` with the app name and a maintainer contact email, as
requested by Open Library for regular use. The app performs one request per
scan and does not make bulk requests.

## iOS baseline

Target iOS 17 or later, which allows the app to use SwiftData. Choose the
exact deployment target while creating the Xcode project.

## Local storage

Use SwiftData for on-device persistence. The book catalog remains stored on
the iPhone.
