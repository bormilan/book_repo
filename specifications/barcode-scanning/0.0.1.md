# Barcode scanning

Barcode scanning is the primary fast path for adding a physical book to the
catalog. The scanner reads an ISBN from the book's barcode; it does not, by
itself, know the book's title or author.

## Supported codes

The app should recognize the book-industry barcode formats:

- EAN-13 barcodes beginning with `978` or `979` (ISBN-13)
- ISBN-10 when it is supplied by a metadata provider or entered manually

Other barcode types should be ignored with a clear message rather than being
added as books.

## Add-book flow

1. The user opens **Scan book**.
2. The camera detects a supported barcode and extracts its ISBN-13.
3. The app checks the local database for that ISBN.
4. If the book already exists, the user is shown the existing entry and can
   choose to view it or add another copy.
5. If it is new, the app looks up metadata when a connection is available.
6. When a lookup returns one or more matches, the app saves the first result
   automatically.
7. If lookup fails or the device is offline, the app opens a manual-entry form
   with the scanned ISBN already filled in.

## Metadata lookup

Barcode scanning and metadata lookup should be separate concerns. A
`BookMetadataProvider` interface can hide the specific external service used
for lookup, allowing the provider to be changed later without changing the
scanner or database.

The returned data may include title, authors, publisher, publication date,
language, and description. The app does not download or store cover images.
The first returned Open Library result is used without an edit step in the
initial release.

## Offline and privacy behavior

- Scanning works entirely on-device.
- The catalog is saved locally.
- A network request is made only when metadata is requested for an unknown
  ISBN.
- The app does not download or store cover images.
- A failed lookup must never prevent the user from adding a book manually.

## Edge cases

- Some books have no barcode or an unreadable barcode: support manual ISBN
  entry and completely manual book creation.
- A barcode may resolve to incomplete or incorrect metadata: retain the ISBN;
  editing imported metadata is out of scope for the initial release.
- A single ISBN can represent multiple owned copies: decide whether the first
  release models copies individually or records a quantity on the book.
- Books without an ISBN, such as older editions, should still be catalogable
  manually.

## Metadata provider

The app uses the **Open Library API** for ISBN lookup. It is a free public API
suited to low-volume, real-time book lookup. No API key is required.

The app identifies itself in requests with a `User-Agent` that includes the
app name and a maintainer contact email. It makes at most one lookup per scan,
well within Open Library's low-volume use expectations.

## Decisions

- Cover images are not stored.
- A successful metadata lookup saves the book automatically.
- If Open Library returns multiple matches, the app saves the first result.
