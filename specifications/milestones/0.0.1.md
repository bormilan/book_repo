# Milestones and deliverables

This plan defines the work required for version 0.0.1: a small iPhone app for
cataloging personal books.

## Milestone 1 — Project foundation

**Deliverables**

- An iOS 17+ SwiftUI and SwiftData Xcode project.
- A `Book` data model stored locally on the iPhone.
- The app launches into an empty collection screen.
- Configuration for Open Library requests, including an identifying
  `User-Agent`.

**Complete when** the project builds and runs in the iPhone Simulator.

## Milestone 2 — Local catalog

**Deliverables**

- A collection list displaying saved books by title and author.
- Books sorted alphabetically by title.
- A book-details screen with the saved metadata.
- Ability to delete a book with confirmation.

**Complete when** a saved book remains in the collection after closing and
reopening the app.

## Milestone 3 — Manual book entry

**Deliverables**

- A manual add-book form.
- Title validation: title is required; ISBN and author are optional.
- Save and cancel actions.

**Complete when** a user can add a book that has neither a barcode nor an ISBN.

## Milestone 4 — Barcode scanning

**Deliverables**

- A camera-based ISBN barcode scanner.
- A clear camera-permission explanation and a usable permission-denied state.
- Detection of ISBN-13 EAN barcodes beginning with `978` or `979`.
- Duplicate handling: scanning an existing ISBN opens its details instead of
  creating another record.

**Complete when** the scanner reads a physical book's ISBN on an iPhone.

## Milestone 5 — Open Library lookup

**Deliverables**

- An Open Library ISBN lookup after a new barcode scan.
- Automatic saving of the first returned result.
- A manual-entry fallback, with the scanned ISBN prefilled, when lookup fails
  or has no result.

**Complete when** scanning a known ISBN adds a correctly identified book and a
failed lookup still lets the user save the book manually.

## Milestone 6 — Release readiness

**Deliverables**

- Error states for no camera access, unsupported barcodes, network failure,
  and unknown ISBNs.
- Basic accessibility checks: readable text, VoiceOver labels, and usable
  controls.
- Testing on a physical iPhone and a clean simulator install.
- A short README with build and configuration instructions.

**Complete when** the app can be installed fresh, catalog books by scan or
manual entry, and retain the collection locally without a crash.

## Version 0.0.1 outcome

The release is complete when a user can maintain a local alphabetical list of
books, add a book manually or by scanning an ISBN, and receive Open Library
metadata when it is available.
