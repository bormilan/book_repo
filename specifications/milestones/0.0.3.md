# Milestones and deliverables

This plan defines version 0.0.3: a metadata lookup reliability release. It
makes lookup failures understandable and improves coverage when Open Library
does not contain the scanned edition.

## Milestone 1 — Explain lookup failures

**Related issue:** [#25 — BOOK-12: Explain metadata lookup
failures](https://github.com/bormilan/book_repo/issues/25)

**Deliverables**

- Separate outcomes for no metadata, network failure, and service failure.
- Clear, accessible feedback explaining why manual entry opened.
- The scanned ISBN retained in every manual fallback.
- Automated coverage for each lookup outcome and its user-facing message.

**Complete when** a user can distinguish a missing catalog record from a
temporary request failure and can continue with the scanned ISBN intact.

## Milestone 2 — Improve metadata coverage

**Related issue:** [#26 — BOOK-13: Improve ISBN metadata lookup
coverage](https://github.com/bormilan/book_repo/issues/26)

**Deliverables**

- A measured investigation of Open Library coverage using representative
  English, non-English, regional-edition, old, and newly published ISBNs.
- A root-cause analysis separating source-data gaps, query limitations,
  response-mapping defects, edition-matching problems, and transient failures.
- Baseline and target coverage metrics for the representative ISBN dataset.
- A documented comparison of viable fallback strategies and providers.
- A decision request recording the selected approach, tradeoffs, credentials,
  privacy implications, usage limits, and rejected alternatives.
- A provider-independent metadata lookup boundary with deterministic fallback
  behavior.
- No title-specific or ISBN-specific lookup rules; the reported Hungarian
  edition remains one regression sample within the broader dataset.
- Regression tests covering primary success, fallback success, non-English
  metadata, total miss, and provider errors.

**Complete when** the investigation identifies and documents the dominant
causes of lookup misses and the implemented general solution demonstrates a
material, measured coverage improvement without mismatching editions. The
originally reported ISBN must pass through the same generic lookup path as
every other ISBN.

## Milestone 3 — Verify version 0.0.3

**Deliverables**

- Full automated test-suite verification.
- Physical-iPhone tests for missing-result feedback and fallback-provider
  success.
- Configuration and README updates for any new provider, with no committed
  secrets.
- Completed implementation diary notes and merged issue-linked pull requests.

**Complete when** v0.0.3 identifies lookup failures clearly, meets the agreed
coverage target across the representative dataset, and passes simulator and
physical-device verification.

## Version 0.0.3 outcome

The release is complete when scanning a valid ISBN either imports the exact
edition from a tested provider chain or explains why metadata could not be
retrieved and preserves a usable manual-entry path.
