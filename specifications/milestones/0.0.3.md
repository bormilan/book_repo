# Milestones and deliverables

This plan defines version 0.0.3: a metadata lookup reliability release. It
makes lookup failures understandable and improves coverage when Open Library
does not contain the scanned edition.

## Milestone 1 — Explain lookup failures

**Related issue:** [#25 — BOOK-12: Explain metadata lookup
failures](https://github.com/bormilan/book_repo/issues/25)

**Deliverables**

- Separate outcomes for no metadata, network failure, and service failure.
- Clear, accessible feedback explaining why manual entry opened.
- The scanned ISBN retained in every manual fallback.
- Automated coverage for each lookup outcome and its user-facing message.

**Complete when** a user can distinguish a missing catalog record from a
temporary request failure and can continue with the scanned ISBN intact.

## Milestone 2 — Investigate metadata coverage

**Related issue:** [#26 — BOOK-13: Investigate ISBN metadata lookup
gaps](https://github.com/bormilan/book_repo/issues/26)

**Deliverables**

- A project-owner-verified real-book test list. BOOK-13 depends on this input;
  see
  [[.agents/decision-requests/BOOK-13-real-book-test-data|BOOK-13 real-book
  test data request]].
- Measured baseline coverage and classified causes for lookup misses.
- A comparison of viable queries and metadata providers.
- A decision request selecting a general approach and coverage target for
  BOOK-14.

**Complete when** the dominant causes are documented and BOOK-14 has an
evidence-based implementation decision and measurable success target.

## Milestone 3 — Implement reliable lookup

**Related issue:** [#30 — BOOK-14: Implement reliable ISBN metadata
lookup](https://github.com/bormilan/book_repo/issues/30)

**Deliverables**

- The general provider/query strategy selected by BOOK-13.
- Exact-ISBN edition matching without book-specific exceptions.
- Stable tests using recorded responses and separate live provider tests using
  the owner-verified real-book list.
- Measured coverage meeting the BOOK-13 target.

**Complete when** the general solution meets its coverage target without
increasing edition mismatches and retains a clear manual fallback.

## Milestone 4 — Verify version 0.0.3

**Deliverables**

- Full automated test-suite verification.
- Physical-iPhone tests for missing-result feedback and fallback-provider
  success.
- Configuration and README updates for any new provider, with no committed
  secrets.
- Completed BOOK-12, BOOK-13, and BOOK-14 diary notes and merged issue-linked
  pull requests.

**Complete when** v0.0.3 identifies lookup failures clearly, meets the agreed
coverage target across the real-book test list, and passes simulator and
physical-device verification.

## Version 0.0.3 outcome

The release is complete when scanning a valid ISBN either imports the exact
edition from a tested provider chain or explains why metadata could not be
retrieved and preserves a usable manual-entry path.
