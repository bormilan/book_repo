# UI pages

This document describes the first-version screens for the personal book
catalog. The interface should prioritize adding books quickly and browsing a
small personal collection without unnecessary steps.

## Collection

The collection page is the home screen and opens when the app launches.

It contains:

- A title such as **My books** and the number of saved books.
- A scrollable list of books sorted alphabetically by title.
- Each row shows title and author; no cover image is displayed or stored.
- A prominent **Scan book** action.
- An **Add manually** action for books without a scannable barcode.
- An empty-state message with the same two actions when there are no books.

Tapping a book opens its details.

## Scan book

The scan page shows a camera preview with a visible scanning frame and a
single clear instruction: point the camera at the book's ISBN barcode.

Behavior:

1. Scan only supported ISBN barcodes.
2. Pause scanning once a barcode is detected, preventing repeated scans.
3. Show a short loading state while Open Library is queried.
4. On a successful lookup, save the first result automatically and return to
   the collection.
5. If lookup fails, offer **Enter details manually** with the ISBN prefilled.
6. Provide a way to cancel and return to the collection.

## Book details

The details page shows all saved metadata for one book:

- Title and author(s)
- ISBN
- Publisher and publication date, when available
- Language and description, when available
- Date added

Actions:

- **Delete** requires confirmation before removing the entry.

## Add book manually

This form is used for manual creation and failed lookups.

Fields:

- Title (required)
- Author(s)
- ISBN
- Publisher
- Publication date
- Language
- Description

For a failed barcode lookup, the ISBN is prefilled. The form has **Save** and
**Cancel** actions.

## Navigation

The first version can use a simple stack rather than a persistent bottom
navigation bar:

```text
Collection
├── Scan book → Collection
├── Add manually → Add book manually → Collection
└── Book details
```

## UI principles

- The most common action, scanning a book, is always easy to reach.
- Do not show cover images.
- Save the first Open Library result automatically after a successful scan.
- Use accessible labels, readable text sizes, and clear error messages.
