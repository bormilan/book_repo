# What is this project?
This project is to provide the simplest way to catalog my books.
A mobile application that stores the books on the device.
# Main features
- Store books with basic data.
- Scan the barcode of a book to recognize it. See
  [[specifications/barcode-scanning/0.0.1|Barcode scanning (v0.0.1)]] for the
  scanning and metadata-lookup design.
- Add or delete books
- List books
